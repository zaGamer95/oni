# CLAUDE.md

Korean Oxygen Not Included (산소미포함) guide site for W's own play and for sharing with friends. Jekyll, deployed by GitHub Actions to https://wonbo.site/oni/ on every push to `main`.

## Read first

- **`appendix/sustainability-context.md`**: the project's context file. Per-dupe needs, crop/critter/generator numbers, stable farm/ranch designs, closed loops, W's current run, and the 2026 patch log (last checked: U60-763796, 2026-11-19). Answer gameplay questions from it, and update it, including its patch log, when numbers change.
- **W's save files**: when W uploads a `.sav`, run `tools/oni-save/oni_report.py` (see its README) and design from that data, not guesses: real cell elements/temperatures, Abyssalite (`Katairite`) and biome borders, each 복제체's attributes, interests, skills and unspent points. Snapshots live in `_sources/saves/cycle-<n>/`.
- When a number differs, the in-game tooltip wins, then the wiki (`https://oxygennotincluded.wiki.gg/wiki/<Page>?action=raw`), then this file.

## Conventions

- The guide is written for **Spaced Out!**. Early/mid/late are defined by research: mid starts at Materials Science Research, late starts at Data Analysis Research.
- **Names come only from `_data/glossary_ko.yml`** (official Klei Korean, built from the game's `strings_preinstalled_ko_klei.po` by `_tools/glossary/build.py`; copy of the .po in the project files `oni-strings/`). Never invent or translate a name yourself. If a term is missing, write the English name and ask W. Write `한글 (English)` on first use in a page so both are visible. After a game update, rebuild the glossary from W's new .po; to fix names in bulk use `_tools/glossary/apply_fixes.py` + `fix_particles.py` (을/를 etc.). Public page: `/appendix/glossary/`.
- Call them "복제체", never 듀플리컨트. Use the Korean game UI terms (와이어, 파이프, 기체 파이프, 환경 특수복). Write names as `한글 (English)`; the English name is the reliable key.
- Pages live in `guide/*.md` with front matter `nav_order` / `nav_num` / `nav_group` / `permalink`. Sidebar groups are in `_data/nav_groups.yml`. Callouts use a blockquote plus `{: .tip|.warn|.danger|.heat}`.
- Top bar has two sections, 가이드 / 사례. Each group in `_data/nav_groups.yml` has `section: guide|case`; the sidebar and prev/next pager show only the current section. Case pages live at `/guide/case/...` with the hub at `/guide/case/` (`guide/case-index.md`); a new case gets its own `section: case` group, and chapters use `nav_key` / `nav_parent`.
- The top-right version badge comes from `_data/versions.yml`. Site default is `game_version` in `_config.yml`; a page (e.g. a case played on an older patch) overrides it with its own `game_version:` front matter key.
- Images: official Klei art and in-game icons with credit. No hand-drawn SVG illustrations. Generated tile-scale plan diagrams are fine, and **every plan diagram must show the tile grid** (1 cell = 1 tile, a stronger line every 10 tiles), coordinate ticks, and dimension lines with the width × height in tiles (W rule, 2026-11-26).
- Blueprints (detailed layouts) are generated by `_tools/blueprint/` (`python3 _tools/blueprint/make.py`; specs in `_tools/blueprint/specs/*.py`, output `_includes/bp/<name>.svg`, used as `<div class="bp-wrap" markdown="0">{% include bp/<name>.svg %}</div>`). Always: 1 cell = 1 tile grid, column/row tick numbers, width×height dimension lines per room, scale bar, buildings as in-game icons at real wiki footprint (`assets/img/icons/`, from `https://oxygennotincluded.wiki.gg/images/<Name>.png`; pass `--icons <dir>` to resize new ones).
