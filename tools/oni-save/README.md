# ONI 세이브 분석 도구

W의 산소미포함 세이브(`.sav`)를 읽어서 설계에 쓸 실제 데이터를 뽑는 스크립트입니다. 추측 대신 이 데이터로 설계합니다.

```bash
pip install numpy pillow
python3 tools/oni-save/oni_report.py "ORAK1 Cycle 191.sav" out/
```

| 출력 | 내용 |
|---|---|
| `report.md` | 월드별 요약: 바이옴, 심성석 셀 수, 복제체, 기지 주변 기체 구성·온도·세균, 전력, 식량, 자원, 건물 수, 복제체 표 |
| `colony.json` | 복제체(능력치·관심·스킬·남은 포인트 추정·트레잇·우선순위), 모든 건물의 셀 좌표·재료·온도, 자원, 전력 |
| `world_<id>_grid.npz` | 월드별 셀 배열: `element`, `temp_c`, `mass_kg`, `germ`, `germ_count`, `biome`(ZoneType 번호), `origin` |
| `world_<id>_map.png` | 1칸 = 1타일 격자 지도. 굵은 선 10타일, 좌표 눈금, 가로·세로 타일 수, 심성석 분홍, 바이옴 경계 노란 선 |

## 좌표

- 게임 셀 좌표는 전체 클러스터 격자 기준이고 **y는 아래가 0**입니다. 지도와 `npz`는 월드 왼쪽 아래를 (0,0)으로 둔 월드 좌표입니다. 전체 좌표 = 월드 좌표 + `origin`.
- 건물 좌표는 건물 기준 셀 하나입니다(여러 칸짜리 건물은 보통 아래 가운데).

## 형식 메모 (저장 버전 7.39, 빌드 764025에서 확인)

- `onisave.py`는 RoboPhred/oni-save-parser(MIT)의 읽기 경로를 Python으로 옮긴 것입니다. 원본은 7.31까지만 지원해서, 타입 템플릿을 그대로 따라가는 방식으로 다시 짰습니다. 템플릿 길이가 안 맞으면 길이만큼 건너뛰고 계속 읽습니다.
- 셀 격자(`SIMSAVE` 블록, 버전 15): 헤더 29바이트, 가장자리 1칸을 포함한 (가로+2)×(세로+2) 셀마다 16바이트 `원소 해시 u32, 온도 K f32, 질량 kg f32, 기타 u32`, 그 뒤에 셀마다 8바이트 `세균 해시 u32, 세균 수 i32`. 원소 해시 = 원소 ID의 SDBM 소문자 해시 (예: `Katairite` = 심성석 = 0x3fe0146e).
- 바이옴은 `Game+GameSaveData.worldDetail.overworldCells`의 다각형을 격자에 칠해서 얻습니다.
- 남은 스킬 포인트는 경험치로 계산한 추정치(15포인트/250사이클, 지수 1.44)입니다. 능력치는 저장된 기본 레벨이라 트레잇·스킬 보너스는 빠져 있습니다. 게임 화면 숫자가 최종 정답입니다.
