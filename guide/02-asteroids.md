## 지형별 첫 행동

| 소행성 | 꼭 할 것 | 하지 말 것 |
|---|---|---|
| 테라 | 늪에서 조류, 사이클 20~30에 전해조 준비 | 는지렁이 (Slime) 근처 오래 머물기 (는지렁이허파) |
| 오세아니아 | **탈염기 (Desalinator)** 연구 일찍 | 쑤심딱지 (Pokeshell) 알 건드리기 |
| 라임 | 농장을 절연 타일로 감싸고 발전기 열로 난방 | 생활 구역 열어 두기 (복제체 감기) |
| 버단트 | 산소석 (Oxylite)으로 초반 산소, 뜨거운 건물 한쪽에 | 열 구역 흩어 놓기 |
| 아보리아 | 산소석으로 시간 벌고 **물 + 전해조**로 빨리 | 산소 확산기에 기대기 |
| 볼카네아 | 화산 쪽 경계를 절연 타일로 | 초반에 화산 쪽으로 파기 |
| 배드랜즈 | 전해조로 일찍, 오염된 물 모으기 | 조류·물 낭비 |
| 아리디오 | 물 절약, 농장은 가장 시원한 곳 | 발전기·전해조를 농장·침실 옆에 |
| 오아시쎄 | 시작 오아시스 물로 화장실 고리 먼저 | 시작 바이옴 경계 파기 |

<details class="nums" markdown="1">
<summary>지형별 추가 메모</summary>

- **라임:** 얼음 (Ice)을 캐서 기지에 두면 녹지만 주변을 식힘. 발전기·전해조를 생활 구역 바로 아래층에 두면 난방.
- **버단트:** 석유층 위치가 불규칙하니 지도 오버레이로 일찍 확인. 냉각은 [장기 평형 설계]({{ '/guide/sustainability/' | relative_url }}).
- **아보리아:** 툰드라가 있어 냉각은 쉬움. 연구는 전력·파이프 우선.
- **볼카네아:** 화산은 증기 터빈 등 열 기술이 생긴 뒤에 금속·열 자원으로.
- **아리디오:** 씨근풀 (Wheezewort) 없음. 온도 오버레이(F4)로 끼니나무 생존 온도 확인.
- **선사 DLC (마리네아·렐리카):** 아직 직접 플레이 정리 전.
</details>
