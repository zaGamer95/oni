## 4교대: 6칸씩 밀기

## 좋아지는 것

{: .ico-grid}
- {% include i.html n="Shower" %} **샤워실** 안 붐빔
- {% include i.html n="Lavatory" %} **화장실** 줄 없음
- {% include i.html n="Mess_Table" %} **식탁** 가장 큰 조 인원만큼
- {% include i.html n="Ladder" %} **통로** 안 막힘
- {% include i.html n="Research_Station" %} **연구** 24시간 가동

> **침대 수는 안 줄어요** (복제체마다 하나). 줄어드는 건 화장실·식탁·샤워기·통로 혼잡. 6명 이상부터 체감.
{: .warn}

<details class="nums" markdown="1">
<summary>시설 개수 기준</summary>

| 시설 | 일정 하나일 때 | 4교대일 때 |
|---|---|---|
| 침대 | 인원수 | **인원수 그대로** (침대는 복제체마다 하나씩 배정되어 나눠 쓰지 않음) |
| 식탁 | 인원수 | 가장 큰 조 인원수 |
| 화장실 | 인원 ÷ 2 정도 | 조마다 1~2개면 충분 (경험치. 한 조 4명까지 화장실 2개) |
| 싱크대·세면기 | 화장실과 같은 수 | 화장실과 같은 수 |
| 샤워기 | 인원수 (목욕 시간에 다 같이 씀) | 가장 큰 조 인원수. 배치도 샤워실 8대면 4교대 32명까지 |

</details>

## 주의할 점

| 할 것 | 이유 |
|---|---|
| **침실은 어둡게** | 다른 조가 깨어 있을 때도 자는 조가 있음 (빛 = 수면 방해) |
| **휴식 → 취침 → 목욕** 순서 유지 | 자기 전에 먹고, 일어나서 볼일 (잠 깨는 사고 방지) |
| 올빼미족 (Night Owl)은 낮·저녁·새벽조 | 21~23칸 보너스를 오전조는 자면서 버림 |
| 아침형 복제체 (Early Bird)은 오전·저녁·새벽조 | 0~4칸 보너스를 낮조는 버림 |

<details class="nums" markdown="1">
<summary>더 자세히</summary>

- 휴식 칸 하나당(첫 칸 제외) 사기 +1, 최대 +4. 지금 2칸 = +1.
- 목욕과 휴식 사이가 10칸 넘게 벌어지면 화장실을 두 번 감.
- 스태미나가 100% 안 되면 취침 뒤 일·목욕 칸까지 계속 잠 (휴식 칸에선 깸). 취침 3칸이면 보통 충분.
- 시끄럽게 잠 (Loud Sleeper)·헛배부름 (Flatulent)은 같은 시간 자는 인원이 적을수록 피해가 작음.

</details>
