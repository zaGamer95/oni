## 초반 임시 배치 (사이클 1~20)

벽·바닥 줄은 **처음부터 후반 도면 위치에.** 포드 바로 위에 화장실을 가장 먼저, 그 위 식당(임시 벽으로 12×5).

<div class="bp-wrap" markdown="0">
{% include bp/core-base-early.svg %}
</div>
<p class="bp-legend">1칸 = 1타일. 위·왼쪽 눈금 = 칸 번호(5칸마다 굵은 선, 10칸마다 더 굵은 선), 노란 치수선 = 방 안쪽 칸 수(벽 제외). 건물·타일은 실제 크기의 인게임 아이콘이고, 아이콘에 마우스를 올리면 이름이 나와요.</p>

**파는 순서**

{: .ico-grid}
1. {% include i.html n="Printing_Pod" %} **포드층**
2. {% include i.html n="Outhouse" %} **화장실층**<br>(포드 위 한 층은 샤워실 자리로 비움)
3. {% include i.html n="Ladder" %} **서쪽 통로**
4. {% include i.html n="Mess_Table" %} **식당층**
5. {% include i.html n="Cot" %} **막사·보관**
6. {% include i.html n="Farm_Tile" %} **온실 A·웅덩이**
7. {% include i.html n="Coal_Generator" %} **발전소 자리**

<details class="nums" markdown="1">
<summary>자리별 크기와 초반에 둘 것</summary>

| 자리 | 크기 | 초반에 둘 것 | 방 |
|---|---|---|---|
| 포드층 (코어 맨 아래) | 24×4 | 포드 + 연구소 + 수동 발전기 + 배터리 | 없음 (발전기가 산업 기계) |
| **화장실층** (포드 위 샤워실 자리 바로 위) | 16×3 = 48 | 피처 펌프 + 세면기·뒷간 2개씩 번갈아. 퇴비는 밖. 오른쪽 7×3은 나중에 기계실 | 변소 (+1) |
| 식당층 (그 위) | 24×5 중 **12×5 = 60** (임시 벽) | 식탁 4 | 식당 (+3) |
| 서쪽 통로 | 3칸 폭 | 사다리 + 소방서 폴 + 식물 칸 (층 바닥 줄은 자연 타일로 남김) | 공원 (+3) → 자연보호구역 (+6) |
| 통로 건너 식당 옆 | 24×4 (주방 자리) | 미생물 걸죽기 + 배급 상자 + 보관함 | 없음 |
| 통로 건너 포드층 옆 | 16×4 = 64 (호화 막사 자리) | 간이 침대 3 | 막사 (+1) |
| 실내 온실 A 자리 (동쪽) | 23×5 | 바닥 줄 재배 타일 20 (끼니나무). 화분은 장식 −10이고 나중에 뜯어야 해서 안 씀 | 없음 |
| 포드층 아래 (예비 자리) | 24×4 | 피처 펌프, 산소 확산기 (임시) | 없음 |
| 동쪽 아래 웅덩이 | 자연 크기 → 30×4 | 그대로 물 저장 → 나중에 깨끗한 물 수조 | 없음 |
| 격벽 줄 아래 (발전소 자리) | 24×4 | 석탄 발전기 1 + 배터리 2 ([10 발전소]({{ '/guide/core-base/power/' | relative_url }})) | 없음 |

</details>

## 초반 시설 → 후반 시설

**섞여 있으면 방 보너스가 안 붙는 것**만 기억하세요: 뒷간이 하나라도 남으면 세척실 ✕, 간이침대가 하나라도 남으면 호화 막사 ✕.

{: .ico-grid}
- {% include i.html n="Outhouse" %} **뒷간·세면기** → {% include i.html n="Lavatory" %} 수세식·싱크대
- {% include i.html n="Cot" %} **간이침대** → {% include i.html n="Comfy_Bed" %} 편안한 침대
- {% include i.html n="Manual_Generator" %} **수동 발전기** → {% include i.html n="Super_Computer" %} 슈퍼 컴퓨터
- {% include i.html n="Microbe_Musher" %} **미생물 걸죽기** → {% include i.html n="Gas_Range" %} 주방
- {% include i.html n="Ration_Box" %} **배급 상자** → {% include i.html n="Refrigerator" %} 냉장고
- {% include i.html n="Mess_Table" %} **식탁 4 + 임시 벽** → {% include i.html n="Water_Cooler" %} 복층 큰 회관

<summary>철거 시점과 그 자리 재활용 (전체 표)</summary>

| 초반 시설 | 자리 | 철거 시점 | 그 자리 재활용 |
|---|---|---|---|
| 뒷간 ×2 + 세면기 ×2 | 화장실층 16칸 | 위생·증류 연구 후 | 같은 방에 **싱크대 2 · 수세식 4 · 싱크대 2** (2칸 폭 × 8 = 16칸). 옆 7×3 기계실에 물 체. 피처 펌프는 폐쇄 루프를 한 번 채운 뒤 철거. **뒷간이 하나라도 남으면 세척실이 안 되니** 다 철거 → 화장실(세척실) +2. 퇴비는 실내 온실 쪽으로 |
| (샤워기 없음) | 포드 바로 위 24칸 | 위생(Sanitation) 연구 후 | **샤워실**: 샤워기 2×4 × 8대. 샤워 1회 사기 +3, 물 16 kg. 화장실과 같은 폐쇄 루프 |
| 간이 침대 ×3 | 통로 건너 16칸 | 편안한 침대 연구 후 | 하나씩 교체. **간이 침대가 하나라도 남으면 호화 막사가 안 되니** 마지막 하나까지 철거 → 편안한 침대 4 = 호화 막사 +2. 위쪽 줄에 개인 침실 6×4를 4개씩 차례로 팜 |
| 수동 발전기 | 포드층 | 격벽 밖 발전소에 석탄 발전기가 돈 뒤 | 그 자리에 **슈퍼컴퓨터** → 연구소와 합쳐 연구실(+10%). 포드 불빛 범위라 작업 속도도 빠름 |
| 미생물 걸죽기 | 통로 건너 24칸 | 주방(전기 그릴) 완성 후 | 같은 칸이 **주방** (그릴 + 향신료 분쇄기 + 냉장고, 식탁 없이) |
| 배급 상자 | 주방 자리 | 냉장고 지은 뒤 | 철거 |
| 식탁 4 + 임시 벽 | 식당층 | 워터 쿨러·장식 연구 후 | 오른쪽에 워터 쿨러(꺼 둠) + 꽃병을 **먼저** 놓고 → 임시 벽 허묾 → 가운데 줄에 발판을 깔아 **복층 큰 회관** 24×5 (+4), 식탁 14까지 |
| (화분 안 씀) | 온실 A 자리 | – | 처음부터 바닥 줄을 재배 타일로 깔아서 철거할 게 없음. 식량이 더 필요해지면 가운데에 재배 타일 한 줄 추가 → 2줄 실내 온실 A (작물 40). 위에 실내 온실 B, 격벽 밖에 외부 온실 |
| 피처 펌프, 산소 확산기 | 포드층 아래 24칸 | 액체 펌프·SPOM 가동 후 | 예비 (병원 등) |
| 공원 (서쪽 통로) | 서쪽 통로 | 통로를 아래로 늘리기 전 | 야생 식물 4개 이상이면 그대로 자연보호구역 +6. 철거할 건 없음 |

</details>

## 확장 규칙 (뜯지 않고 늘리기)

- **통로는 위아래로만.** 위치는 절대 안 옮김.
- 새 방은 **바깥쪽에**, 가로 = 최대 크기 ÷ 4 (개인 침실 6).
- 코어는 위로, 침실은 서쪽, 농장·목장은 동쪽, 산업은 격벽 아래로.
- 격벽 안을 늘릴 땐 **새 칸을 먼저 단열로 감싼 뒤** 옛 격벽을 허묾.
- 큰 방이 될 자리는 **임시 벽**으로 나눠 두고 조건을 먼저 채운 뒤 허묾.
- 파이프·와이어는 바닥 줄(5칸 간격)에 → 방을 바꿔도 안 뜯음.
- 기지가 100칸 가까워지면 수송 튜브 (Transit Tube).
