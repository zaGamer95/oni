## 지금 할 일 (4명, 사이클 5 전후)

{: .ico-grid}
1. {% include i.html n="Farm_Tile" %} **온실 A 23×5**<br>바닥 줄 재배 타일 20
2. {% include i.html n="Mess_Table" %} **식당 12×5**<br>임시 벽 + 식탁 4
3. {% include i.html n="Microbe_Musher" %} **미생물 걸죽기 (Microbe Musher)**<br>이빵 (Liceloaf)
4. {% include i.html n="Ration_Box" %} **배급 상자** 식당 밖 통로 옆

연구: 기본 재배 → **식사 준비 (Meal Preparation)** → 농업 → 전기 그릴.

## 얼마나 키우나

> **1명 = 하루 1,000 kcal = 끼니나무 5그루** (이빵이면 3.5). **재배 타일 20개 한 줄 = 4명분.** 첫 수확은 심고 3사이클 뒤.
{: .tip}

<details class="nums" markdown="1">
<summary>음식별 칼로리와 1명당 그루 수</summary>

| 음식 | 만드는 법 | 칼로리 | 복제체 1명당 | 추가로 드는 것 |
|---|---|---|---|---|
| 끼니이 (Meal Lice) 날것 | 끼니나무가 3사이클마다 1개 | 600 → 하루 200/그루 | **5그루** | 흙 10 kg/그루/사이클 |
| **이빵 (Liceloaf)** | 분쇄기: 열매 2개(1,200) + 물 50 kg | 1,700 | **약 3.5그루** | 물 약 30 kg/사이클 |
| 끼니 절임 (Pickled Meal) | 그릴: 열매 3개 | 1,800 (그대로) | 5그루 | 32사이클 보관, 세균 제거 |
| 센털베리 (Bristle Berry) 날것 | 센털꽃이 6사이클마다 1개 | 1,600 → 하루 267/그루 | **3.75그루** | 물 20 kg/그루/사이클, 빛 |
| **센털베리구이 (Gristle Berry)** | 그릴: 센털베리 1개 | 2,000, 품질 +1 | **3그루** | 그릴 스킬 |
| 걸죽바 (Mush Bar) | 분쇄기: 흙 75 + 물 75 kg | 800 | – | 세균 1,000 이상 붙어 나옴. 비상용 |

</details>

<div class="bp-wrap" markdown="0">
{% include bp/mess-late.svg %}
</div>
<p class="bp-legend">1칸 = 1타일. 위·왼쪽 눈금 = 칸 번호(5칸마다 굵은 선, 10칸마다 더 굵은 선), 노란 치수선 = 방 안쪽 칸 수(벽 제외). 건물·타일은 실제 크기의 인게임 아이콘이고, 아이콘에 마우스를 올리면 이름이 나와요.</p>

{: .ico-grid}
1. {% include i.html n="Refrigerator" %} **냉장고** → 배급 상자 철거
2. {% include i.html n="Gas_Range" %} **주방** 그릴·향신료 분쇄기 (식탁 없이)
3. {% include i.html n="Water_Cooler" %} **워터 쿨러 + 장식 20** 먼저
4. {% include i.html n="Mesh_Tile" %} **임시 벽 허물기** → 큰 회관 +4
5. {% include i.html n="Ladder" %} **발판 + 사다리** 위층 식탁

> **조건을 먼저 채우고 벽을 허무세요.** 식당 최대가 64라 그냥 허물면 보너스가 사라집니다. 식당 안엔 침대·화장실·분쇄기·배급 상자·재배 박스 금지 (장식 감소).
{: .warn}

> **워터 쿨러는 지어 놓고 꺼 두기** (W 꿀팁). 오락 건물 조건은 채우고 물·운반은 아낌.
{: .tip}

<details class="nums" markdown="1">
<summary>초반 식당 칸별 배치</summary>

| 칸 | 크기 | 놓을 것 | 메모 |
|---|---|---|---|
| 식당 (1~12번) | 12×5 = 60 | **식탁 4개** (4·6·8·10번) | 식당(Mess Hall)은 **최대 64칸**이라 120칸 그대로 두면 식당 보너스(+3)가 없음. 그래서 임시 벽 |
| 임시 벽 (13번) | 1칸 | 벽 | 큰 회관 조건을 채운 뒤 허묾 |
| 오른쪽 (14~24번) | 11×5 | 비워 둠 → 워터 쿨러·꽃병 자리 | 방은 아님 |
| 보관·조리 | 서쪽 통로 건너 24×4 (나중에 주방) | 미생물 걸죽기 2×3, 배급 상자 2×2, 보관함 | 분쇄기는 **장식 −15 (반경 3)** 이라 식당 밖에 |

- 문은 양 끝 바닥. 배급 상자는 보관·조리 칸의 통로 쪽 문 바로 옆.

</details>

<details class="nums" markdown="1">
<summary>복층 큰 회관 칸별 배치</summary>

| 자리 | 놓을 것 |
|---|---|
| 가운데 줄 (위에서 3번째) 4~21번 | **발판 타일** 18칸. 아래층·위층 모두 높이 2라 복제체가 지나다닐 수 있음 |
| 3번, 22번 | **방 안 사다리** (위아래 전체). 발판 양 끝에서 위층으로 올라감 |
| 아래층 5~19번 홀수 | **식탁 8개** |
| 위층 6~16번 짝수 | **식탁 6개** |
| 위층 18~19번 | **워터 쿨러** (오락 건물 조건) |
| 아래층 2번 | 꽃병 + 깎아지른찔레 (장식 20 이상 조건) |

- 방 크기 120 − 발판 18 = 102칸 (큰 회관 32~120).
- 식탁 14개면 4교대 조당 3~4명에 넉넉. 소금을 채우면 먹을 때마다 사기 +1.
- 냉장고 1×2, 100 kg, 1°C 보관. 깎아지른찔레 (Bluff Briar)가 장식 25.

</details>

<p class="bp-legend">1칸 = 1타일. 위·왼쪽 눈금 = 칸 번호(5칸마다 굵은 선, 10칸마다 더 굵은 선), 노란 치수선 = 방 안쪽 칸 수(벽 제외). 건물·타일은 실제 크기의 인게임 아이콘이고, 아이콘에 마우스를 올리면 이름이 나와요.</p>

{: .ico-grid}
- {% include i.html n="Mealwood" %} **온실 A: 끼니나무** 2줄 40그루 = 8명. 비료 불필요
- {% include i.html n="Bristle_Blossom" %} **온실 B: 센털꽃** 15×7, 24그루. 빛 200 lux + 재배스테이션
- {% include i.html n="Ceiling_Light" %} **천정등** 12칸 줄에 2개

> **재배 박스 (Planter Box) 말고 재배 타일 (Farm Tile).** 장식 −10이 없고 바닥 자체가 되어 2줄 쌓기 쉬움. 식탁과 같은 연구라 그때부터 무조건 재배 타일.
{: .tip}

| 단계 | 온실 A | 온실 B | 하루 칼로리 | 먹일 수 있는 인원 |
|---|---|---|---|---|
| 지금 | 재배 타일 20 (끼니나무) | – | 4,000 | 4명 |
| 가운데 줄 추가 | 2줄 40 (끼니나무) | – | 8,000 | 8명 |
| 조명·그릴 후 | 2줄 40 | 센털꽃 24 (그릴) | 16,000 | 16명 |
| 비료 계속 | 2줄 40 | 센털꽃 24 + 비료 | 약 24,000 | 약 24명 |

<details class="nums" markdown="1">
<summary>재배 박스 vs 재배 타일</summary>

| | 재배 박스 (Planter Box) | 재배 타일 (Farm Tile) |
|---|---|---|
| 연구 | 기본 재배 (Basic Farming) | **식사 준비 (Meal Preparation)**, 식탁과 같은 연구 |
| 비용 | 흙 100 kg | 흙 100 kg (같음) |
| 성장 속도·수확량 | 같음 | 같음 |
| 장식 | **−10** (반경 2) | **0** |
| 자리 | 바닥 위에 하나 더 얹음 → 줄마다 1칸 더 높아짐 | **바닥 자체가 됨** → 높이 1칸 절약, 2줄 쌓기 쉬움 |
| 단점 | – | 바닥 이동 속도 보너스 없음, 기체를 막음 |

</details>

<details class="nums" markdown="1">
<summary>온실 A 2줄 만드는 법과 흙</summary>

1. 바닥 줄은 그대로, 위에서 3번째 줄에 재배 타일 20개 추가 → 40그루.
2. 통로 쪽 2칸은 일반 타일(위층 발판), 맨 끝 1칸 사다리. 작업대(2×3)는 들어가지 않음.
3. 흙: 그루당 하루 10 kg → 20그루 200 kg/사이클. 뒷간의 오염된 흙은 퇴비(하루 흙 60 kg)로.

</details>

<details class="nums" markdown="1">
<summary>온실 B 줄별 구성과 물·비료</summary>

| 줄 (위에서) | 내용 |
|---|---|
| 1 | 조명 줄: 천정등 2개 |
| 2~3 | 센털꽃 12그루 |
| 4 | 재배 타일 12개 |
| 5 | 조명 줄: 천정등 2개 (재배 타일 아래에 매닮) |
| 6~7 | 센털꽃 12그루 |
| 바닥 | 재배 타일 12개 |
| 통로 쪽 끝 3칸 | 맨 끝 1칸 사다리 · 4번 줄 2칸은 일반 타일(위층 발판) · 그 아래 6~7번 줄과 5번 줄에 **재배스테이션 2×3** (아래층이 3칸 높이라 들어감) |

- 천정등 1×1, 10 W, 1,800 lux, 범위 8칸. 방 크기 91 (최대 96).
- 24그루 → 날것 6,400 kcal, 센털베리구이 8,000 kcal.
- 물 그루당 20 kg/일 → 480 kg/사이클. 나중엔 수경재배장 (Hydroponic Farm)으로 파이프 직결.
- 재배스테이션: 비료 5 kg → 1그루 성장 2배 (1사이클 + 농업 레벨당 0.1). 비료 합성기 1대 72 kg/일 ≈ 14그루.

</details>
