## 초반 ①: 시작 행성 세우기

{% include shot.html src="case1-start-planet.jpg" caption="시작 행성 Persephazon (Terrania). 가운데 단열 격벽 안이 중앙 기지, 왼쪽 아래 노란 칸이 온실, 맨 아래는 마그마 바이옴." %}

가이드 [8 중앙 기지 배치도]({{ '/guide/core-base/' | relative_url }}) 격자 그대로. 가이드와 다르게 한 것:

{: .ico-grid}
- {% include i.html n="Cool_Steam_Vent" %} **서늘한 증기 벤트 (Cool Steam Vent) → SPOM 물** 터빈 없이 96°C까지만 식힘
- {% include i.html n="Grubfruit_Plant" %} **야생 벵이벵이 (Grubgrub)** 끼니나무 온실 꽃가루받이 +50%
- {% include i.html n="Drecko" %} **플라스틱 = 번질한 기끌이 (Glossy Drecko)** 원유가 없어서
- {% include i.html n="Uranium_Ore" %} **우라늄 광석은 남겨 둠** 나중에 수동 래드볼트 생성기 (Manual Radbolt Generator)

## 초반 ②: 안정화 → 두 번째 행성

> **배운 것:** 첫 행성에만 오래 있으면 자원 종류가 모자라 발전이 느립니다. 안정되면 **텔레포터로 두 번째 행성을 같이 키우기** → 일반 가이드 [16 두 번째 행성 병행 개발]({{ '/guide/second-planet/' | relative_url }}).
{: .heat}

{% include shot.html src="case1-second-planet.jpg" caption="텔레포터로 이어진 두 번째 행성 Oozato (기름 늪). 지표 바로 아래 가운데에 출장소." %}

{: .ico-grid}
1. {% include i.html n="Printing_Pod" %} **[안정화 체크리스트]({{ '/guide/second-planet/#언제-보내나-안정화-체크리스트' | relative_url }}) 통과** 6명
2. {% include i.html n="Teleporter_Transmitter" %} **배시시 보냄** 굴착+건설
3. {% include i.html n="Cryotank_3000" %} **냉동 탱크 해동 → 노먼** 청소+특수복
4. {% include i.html n="Cot" %} **출장소** 침대·뒷간·보관함
5. {% include i.html n="Supply_Teleporter_Input" %} **공급 텔레포터** 현장 연구 (Field Research)로 양쪽 켜기

<details class="nums" markdown="1">
<summary>두 행성이 주고받는 것</summary>

- Oozato → Persephazon: 원유, 황, 금속 광석
- Persephazon → Oozato: 정제 금속, 씨앗, 음식
- 사이클 108엔 공급 텔레포터 아직 안 켬. 양과 순서는 [3장 두 기지 교환 구조]({{ '/guide/case/terrania-1/link/' | relative_url }}).

</details>
