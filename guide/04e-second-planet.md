## 한 줄 요약

- **Spaced Out!은 행성마다 맡은 자원이 다릅니다.** 시작 행성에만 오래 머물면 석유·황·우라늄 같은 자원이 없어서 연구와 건설이 같이 멈춰요.
- **시작 행성이 안정되면 (아래 체크리스트) 바로 텔레포터로 두 번째 행성에 1~2명을 보내고, 두 기지를 같이 키웁니다.** 텔레포터는 연구가 필요 없어서 초반 안에 할 수 있어요.
- **세 번째 행성은 첫 로켓으로 엽니다.** Terrania 클러스터의 텔레포터는 시작 행성과 기름 늪 소행성 한 쌍뿐이에요.
- 실제로 이렇게 키운 판은 [실제 플레이 사례 1]({{ '/guide/case/terrania-1/' | relative_url }})에 기록했습니다.

## 왜 병행해야 하나

시작 행성 하나로는 자원 종류가 한정돼 있습니다. Terrania 클러스터 기준으로 보면 이렇습니다.

| 자원 | 시작 행성 (Terrania) | 두 번째: 기름 늪 (Oily Swamp) | 세 번째: 방사능 숲 (Irradiated Forest) |
|---|---|---|---|
| 원유·석유 | **없음** | 석유층·원유 | |
| 황 | 황무지(Wasteland) 바이옴에 조금 | **황 분출구 (항상 있음)** | |
| 우라늄 | 있을 수도, 조금 | | **방사능 바이옴 (본산지)** |
| 플라스틱 | 번질한 기끌이 (Glossy Drecko) 목장으로만 | 원유 → 정유 → 폴리머 프레스 | |
| 복제체 | 프린팅팟 | **냉동 탱크 1명 (공짜)** | |
| 가는 법 | | **텔레포터** (연구 불필요) | 첫 로켓 (3칸) |

- 사람이 한 번 건너가는 데는 텔레포터 충전 **5사이클**이 걸리지만, 자원은 **공급 텔레포터**로 쉬지 않고 오갑니다. 일찍 열수록 오래 받아요.
- 두 번째 행성은 "잠깐 가서 캐 오는 곳"이 아니라 **같이 크는 두 번째 기지**로 봅니다. 상주자가 있으면 그 사이 시작 행성은 원래 하던 일을 그대로 합니다.

## 언제 보내나: 안정화 체크리스트

연구 기준으로는 [7 초반 테크]({{ '/guide/research/early/' | relative_url }})의 **3구간(SPOM·단열·물)이 끝날 무렵**, 대략 사이클 25~45입니다. 아래가 다 되면 보내세요.

- [ ] **산소**: SPOM이나 전해조로 산소가 남는다 (복제체 1명당 100 g/s 이상)
- [ ] **식량**: 하루 생산 ≥ 소비이고, 창고에 3사이클치 이상
- [ ] **물**: 무한 물원 연결 (Terrania는 서늘한 증기 벤트)
- [ ] **화장실·샤워**가 돌아가고 오염된 물이 쌓이지 않는다
- [ ] **전력**: 스마트 배터리로 발전기가 알아서 켜지고 꺼진다
- [ ] **스트레스**: 오르는 복제체가 없다
- [ ] **떠나는 사람이 빠져도** 연구·농사·건설이 돌아간다

환경 특수복과 연구는 **필요 없습니다.** 도착 지점(텔레포터 폐허)은 보통 숨 쉴 수 있는 곳이에요. 그래도 보내기 전에 별지도에서 소행성을 눌러 대기를 확인하세요.

## 텔레포터 두 종류

둘 다 시작 행성과 두 번째 행성에 **하나씩 폐허로 묻혀 있어서 양쪽으로 오갈 수 있습니다** (공식 위키).

| | 텔레포터 송신기 (Teleporter Transmitter) | 공급 텔레포터 입력 (Supply Teleporter Input) |
|---|---|---|
| 크기 | 4×3 | 4×3 |
| 보내는 것 | **복제체** | **고체·액체·기체** |
| 조건 | 한 번 쓰면 **5사이클 충전** | **Field Research 스킬** 복제체가 한 번 켜야 함 |
| 목적지 | 정해진 한 곳 | 정해진 한 곳 (공급 텔레포터 출력) |
| 같이 있는 것 | 두 번째 행성 쪽엔 냉동 탱크 | 컨베이어 적재기, 와이어 |

> **Field Research**는 연구 전담 복제체가 찍는 스킬입니다. 공급 텔레포터는 양쪽에서 한 번씩 켜야 하니, **연구원이 두 번째 행성에 한 번 다녀오거나** 처음 보내는 복제체가 스킬을 찍고 가세요. 텔레포터 충전 때문에 왕복은 최소 10사이클입니다.
{: .tip}

## 병행 개발 순서

### 1단계: 출장소 (도착 후 ~5사이클)

1. **냉동 탱크 해동** → 복제체 1명 추가. 해동한 복제체와 같이 10사이클 동안 사기 +6.
2. 침대 1~2개, 뒷간, 식량 보관함.
3. **공급 텔레포터 가동** (양쪽 다).

### 2단계: 자립 (그다음 ~15사이클)

상주자가 1~2명이면 **현지에서 숨 쉬고 먹는 게** 운반이 적습니다.

- 산소: 현지 산소원 (전해조, 조류 배양기 등) 한 대
- 식량: 끼니나무 몇 그루, 또는 시작 행성에서 공급 텔레포터로 보냄
- 화장실 → 샤워까지. 상주자도 사기가 필요해요 (침실·식탁)
- 전력: 작은 발전기 + 배터리

### 3단계: 자원 공장

| 방향 | 보내는 것 |
|---|---|
| 두 번째 → 시작 | **원유** (석유·플라스틱·석유 발전기), **황**, 금속 광석 |
| 시작 → 두 번째 | 정제 금속, 씨앗, 음식, 필요한 건물 재료 |

- 기름 늪의 **황 분출구**는 액체 황을 식혀 고체 황으로 만들면 **벵이벵이·단벌레 목장**과 벵이과실 농사로 이어집니다. 벵이벵이가 황을 먹고 진흙을 내고, 진흙은 흙+물이 되니 **황 분출구 하나로 자립 기지**가 됩니다 (공식 위키 Oily Swamp Asteroid).

## 세 번째 행성: 첫 로켓

Terrania 클러스터의 텔레포터는 **시작 행성 ↔ 기름 늪** 한 쌍뿐입니다. 세 번째부터는 로켓이에요.

- **방사능 숲 (3칸)**: 우주 프로그램 + 이산화탄소 엔진 (초반 4구간). 우라늄 → 래드볼트 → 5단계 기술.
- 그 뒤 행성들은 사거리가 긴 엔진이 생긴 뒤입니다. 행성별 거리와 엔진 사거리는 [18 8명 중반 설계·행성 진출]({{ '/guide/midgame-8/#다른-소행성-진출-terrania-클러스터' | relative_url }}).

## 사람 배치

| 시점 | 시작 행성 | 두 번째 행성 | 로켓 |
|---|---|---|---|
| 처음 보낼 때 | 나머지 전부 | **운반·특수복** 1명 | |
| 냉동 탱크 해동 후 | 나머지 | 1~2명 (해동 복제체가 남거나 시작 행성으로) | |
| 첫 로켓 | 나머지 | 1~2명 | 조종사 + 1명 |

- 두 번째 행성에 보낼 첫 사람은 **Supplying + Suit Wearing** 관심 복제체가 좋습니다. 운반이 주 업무이고, 석유층·녹 바이옴은 나중에 특수복이 필요해요.
- 시작 행성의 4교대는 그대로 두고, 두 번째 행성은 **1~2명이 같은 시간에 쉬는 일정**을 따로 만듭니다.
