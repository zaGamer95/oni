## 방 크기 전체 표

공식 위키(Room Overlay) 기준입니다. 크기는 **벽 안쪽 칸 수**입니다. "배치도 크기"는 [전체 도면]({{ '/guide/core-base/#후반-완성-배치도' | relative_url }})에 실제로 그린 크기예요.

| 방 | 크기 범위 | 배치도 크기 | 조건 | 효과 |
|---|---|---|---|---|
| 변소 (Latrine) | 12~64 | 16×4 = 64 | 간이 화장실 + 세면기 | 사기 +1 |
| 화장실 = 세척실 (Washroom) | 12~64 | **16×3 = 48** (싱크대 2 · 수세식 4 · 싱크대 2, 높이 3) | 수세식 화장실 + 싱크대(Sink), **간이 화장실 없음** | 사기 +2 |
| 막사 (Barracks) | 12~64 | 16×4 = 64 (초반, 나중에 호화 막사) | 침대 1개 이상 | 사기 +1 |
| 호화 막사 (Luxury Barracks) | 12~64 | **16×4 = 64** (편한 침대 4, 4칸 폭) | 편한 침대, **간이 침대 없음**, 장식 1, 천장 4칸 | 사기 +2 |
| 개인 침실 (Private Bedroom) | 24~64 | **6×4 = 24** (침대 4칸 + 장식 2칸) | 편한 침대 **딱 1개**, 장식 2, 천장 4칸, **뒷벽 전부** | 사기 +3 |
| 식당 (Mess Hall) | 12~64 | 초반 임시 벽으로 **12×5 = 60** | 식탁 | 사기 +3 |
| 샤워실 (방 종류 아님) | 제한 없음 | **16×4** (샤워기 2×4 × 8) | 샤워기(Shower), 위생 연구 | 샤워 1회 사기 +3 (약 1사이클), 물 16kg |
| 큰 회관 (Great Hall) | 32~120 | **24×5 = 120, 복층** (발판 18칸 빼면 102) | 식탁 + 장식 20 이상 1개 + 오락 건물 | 사기 +4 |
| 연회장 (Banquet Hall) | 32~120 | 30×4 = 120 | 공용 식탁(Communal Table), 장식, 오락 건물, 장식품 전시, **식탁 없음** | 사기 +6 |
| 주방 (Kitchen) | 12~96 | **24×4 = 96** | 향신료 분쇄기 + 그릴/가스레인지 + 냉장고, **식탁 없음** | 향신료 사용 |
| 연구실 (Laboratory) | 32~120 | **24×4 = 96** (포드 포함) | 연구 건물 2개 | 연구 +10%, 지오튜너·관제소 사용 |
| 온실 (Greenhouse) | 12~96 | 15×7 = 91칸 (3칸 높이 층, 작업대 들어감). 23×5 끼니나무 농장은 작업대가 안 들어가 방 아님 | 농업 작업대 | 비료로 성장 2배 |
| 목장 (Stable) | 12~96 | **24×4 = 96** (주둥가리·기끌이) / 12×8 = 96 (헐떡이) | 목장 건물 (손질 작업대 등) | 동물 손질 |
| 발전소 (Power Plant) | 12~96 | **24×4 = 96** | 대형 발전기 + 전력 건물 2개 | 마이크로칩으로 발전 +50% |
| 오락실 (Recreation Room) | 12~96 | **24×4 = 96** | 오락 건물 + 장식 | 휴식 시간 사기 보너스 |
| 마사지실 (Massage Clinic) | 12~64 | **16×4 = 64** | 마사지 테이블 + 장식 | 스트레스 감소 2배 |
| 병원 (Hospital) | 12~96 | 24×4 = 96 | 의료 건물 + 화장실 + 식탁 | 병 전파 감소 |
| 공원 (Park) | 12~64 | 초반 사다리 통로 3×21 ≈ 59 | 공원 표지판 + 야생 식물 2 | 지나가면 사기 +3 |
| 자연보호구역 (Nature Reserve) | 32~120 | **사다리 통로 3×28 ≈ 79** | 공원 표지판 + 야생 식물 4 | 지나가면 사기 +6 |

> 발전소·온실·목장·주방 말고는 거의 다 **산업 기계 금지**입니다. 수동 발전기를 포함한 모든 발전기, 전기분해기, 물 정화기, 펌프, 금속 정제기가 산업 기계예요. 반대로 산소 확산기, 조류 테라리움, 보관함, 배터리, 미생물 분쇄기, 전기 그릴, 냉장고, 퇴비 더미는 산업 기계가 **아닙니다**.
{: .warn}

## 생활 구역 방 배치

매일 모든 복제체가 들르는 네 곳(침실 · 샤워실 · 식당 · 화장실)을 가운데에 모으는 게 목표입니다. 코어(24칸 폭)는 W 기존 가이드 순서대로 **포드 → 샤워실 → 화장실 → 식당**을 아래에서 위로 쌓고, 서쪽에 침실 블록, 동쪽에 실내 농장·목장을 둡니다.

| 층 (위 → 아래) | 서쪽 (바깥 ← 통로) | 코어 24칸 | 동쪽 (통로 → 바깥) |
|---|---|---|---|
| 1 | 개인 침실 6×4 × 4 + 현관 | 오락실 | 작업장 (저장 상자·제작) |
| 2 | 주방 24 | **복층 큰 회관** 24×5 (식탁 14) | 실내 온실 B (센털꽃, 15×7) |
| 3 | 개인 침실 6×4 × 4 + 현관 | **화장실 (세척실)** 16×3 + **기계실** 7×3 (물 정화기·모래·갈대) | ↑ |
| 4 | 개인 침실 6×4 × 4 + 현관 | **샤워실** 16×4 (샤워기 8) + 여유 7×4 | 실내 온실 A (끼니나무, 23×5) |
| 5 | 마사지실 16 · 호화 막사 16 | **포드층 연구실** (포드 + 연구소 + 슈퍼컴퓨터) | 실내 목장: 주둥가리 24 |
| 6 | 실내 목장: 기끌이 24 | 예비 (병원 등) | 깨끗한 물 수조 30 |

- **침실은 한 블록**에 모았습니다 (W 기존 가이드 방식). 개인 침실 12개 + 호화 막사 4명 = 16명분이고, 각 침실 줄 끝(통로 쪽) 5칸은 **현관**(꽃병·장식)입니다. **환경 특수복 거치대는 침실 앞에 두지 않고** 위험 지역으로 나가는 출구(텔레포터·격벽 에어락 앞)에 체크포인트와 같이 둡니다. 실내만 다니면 특수복이 필요 없으니까요.
- 서쪽 3칸 통로가 자연보호구역이라 침실에서 나오면 **바로 보호구역을 지나** 코어로 들어갑니다.
- 코어의 식당(높이 5)과 화장실(높이 3)은 합쳐서 9칸이라, 양옆의 보통 두 층(4 + 바닥 + 4)과 높이가 같습니다. 그래서 양옆 격자는 그대로예요.
- 화장실 옆 기계실(물 정화기·갈대)과 바로 아래 샤워실을 한 루프로 묶어요. 배관은 [화장실·샤워실 폐쇄 루프]({{ '/guide/core-base/envelope/' | relative_url }}#화장실샤워실-폐쇄-루프)에 있어요.
- **샤워실은 포드 바로 위, 화장실 바로 아래**입니다. 바닥 한 줄 사이라 샤워실·화장실·물 정화기를 **한 폐쇄 루프**로 짧게 묶을 수 있어요. 화장실과 식당은 높이를 맞춘 짝이라 붙여 둡니다.

## 한 방에 같이 두면 안 되는 것 (중첩 불가)

방 조건끼리 부딪혀서, 업그레이드하려면 **초반 건물을 꼭 철거해야** 하는 조합입니다.

| 같이 두면 | 결과 |
|---|---|
| 간이 화장실 + 수세식 화장실 | 세척실 안 됨 (간이 화장실 방으로 남음) |
| 간이 침대 + 편한 침대 | 호화 막사 안 됨 (막사로 남음) |
| 편한 침대 2개 이상 | 개인 침실 안 됨 (호화 막사가 됨) |
| 식탁 + 주방 설비 | 주방 안 됨. 주방은 **식탁 없는 별도 방** |
| 식탁 + 공용 식탁 | 연회장 안 됨 |
| 식탁 + 침대 (한 방) | 두 조건을 같이 만족 → **기타 방**, 보너스 0 |
| 수동 발전기·펌프·전기분해기 등 + 생활 방 | 산업 기계라 방 보너스 사라짐 |
| 공원 + 자연보호구역 | 겹쳐서 받지 않음, +6이 +3을 덮어씀 |
