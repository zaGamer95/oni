## 쇄석기

광석 100 kg → **정제 금속 50 + 모래 50**, 40초, 240 W. 10회 ≈ ⅔ 사이클, 광석 총 1,800 kg (건설 800 포함). 모래는 물 체 필터로.

<details class="nums" markdown="1">
<summary>쇄석기 수치와 10회 계산</summary>

| 항목 | 값 |
|---|---|
| 크기 · 재료 | 4×4 · 금속 광석 800 kg |
| 전력 | 240 W (일반 와이어 OK) |
| 1회 | 광석 100 kg → **정제 금속 50 kg + 모래 50 kg**, 40초 (복제체 기계 능력으로 단축) |
| 열 | 작동 중 **16 kDTU/s** → 1회 640 kDTU |


| 계산 | 값 |
|---|---|
| 시간 | 10회 × 40초 = 400초 ≈ **⅔ 사이클** (복제체 1명) |
| 전력 | 240 W × 400초 = **96 kJ** (석탄 발전기 1대 약 2.7분) |
| 열 | 16 kDTU/s × 400초 = **6,400 kDTU**. 격벽 밖 정제 칸이라 괜찮음 |
| 부산물 | 모래 500 kg. 물 체 (Water Sieve) 필터로 그대로 씀 |
| 광석 총량 | 분쇄기 건설 800 + 분쇄 1,000 = **금속 광석 1,800 kg** |

</details>

## 금속 제련소로 넘어가기

{: .ico-grid}
- {% include i.html n="Thermo_Aquatuner" %} **시점** 냉방실(오염된 물 20톤) 뒤
- {% include i.html n="Research_Station" %} **연구** 무차별 정제 → 정제된 혁신 → 제련
- {% include i.html n="Heavi-Watt_Joint_Plate" %} **전력 1.2 kW** 발전소 헤비와트에 연결판
- {% include i.html n="Liquid_Pump" %} **냉각수** 오염된 물, 냉방실 물속으로

> **구리는 냉방실 55°C 아래, 철은 40°C 아래**일 때 몰아서 (정제기 과열 75°C). 강철은 증기 터빈 + 두 번째 조절기 뒤. 깨끗한 물 수조엔 절대 연결 금지, 정제기 자동 소독은 끔.
{: .heat}

(석탄 발전기 1대 = 5,400 kDTU/사이클)

- 구리 1회 = 석탄 발전기 하루 6대분 열. 냉각수 400 kg은 1회에 구리 +19°C, 철 +32°C.
- 냉방실 물 20톤 기준 1회 상승: 구리 약 0.4°C, 철 0.65°C, 강철 1.1°C.

</details>

<details class="nums" markdown="1">
<summary>제련소 조건 표</summary>

| 조건 | 값 | 메모 |
|---|---|---|
| 시점 | **냉방실(오염된 물 20톤)이 생긴 뒤** | 정제 1회에 냉방실 물이 구리 약 +0.4°C, 철 +0.65°C, 강철 +1.1°C. 정제기 과열 75°C 때문에 **구리는 냉방실 55°C 아래, 철은 40°C 아래**일 때. 강철은 증기 터빈 + 두 번째 조절기 뒤 |
| 연구 | 무차별 정제 → **정제된 혁신** → **제련** | 정제된 혁신에서 소방서 폴·온도변환 판도 열림 (이건 일찍 해도 됨) |
| 건설 | 3×4, **아무 암석 800 kg** | 정제 금속 필요 없음 |
| 1회 | 광석 100 kg → **정제 금속 100 kg**, 40초 | 광석 효율은 분쇄기의 2배 |
| 전력 | **1.2 kW** → 1회 48 kJ | 일반 와이어(1 kW)에 물리면 과부하 |
| 냉각수 | 액체 400 kg 이상 (800~1,200 kg 권장) | 입·출력 파이프 둘 다 필요 |
| 과열 | 75°C | |

- 일찍 써야 하면 격벽 밖 50톤 이상 웅덩이에 열을 버리고, 금(열 ⅓)부터.
- 1회 48 kJ → 석탄 발전기 2대 이상 또는 스마트 배터리 2개가 찼을 때.

</details>

<details class="nums" markdown="1">
<summary>계산 정정 기록 (1~3)</summary>

> **정정 3:** 정정 2에서 "구리 한 번에 냉방실 물 20톤이 390°C 오른다"며 정제기를 증기 터빈 뒤로 미뤘는데, 단위를 1,000배 틀렸습니다. 실제는 **약 0.39°C**(32,792 kDTU ÷ 20톤 × 4.179). 그래서 시점을 다시 **"냉방실이 생긴 뒤"**로 고쳤어요. 열은 여전히 냉방실에 쌓이니 터빈은 결국 필요합니다.
>
> **정정 2:** 열액체조화기만으로는 열이 냉방실 물에 쌓이기만 해서, 정제기 시점을 "냉방 루프 뒤"에서 "증기 터빈 뒤"로 고쳤습니다.
>
> **정정 1:** 처음에 "오염된 물 수조에 돌리면 한 번에 +0.11°C라 냉방 없이 된다"고 썼는데, 계산 자체는 맞아도 **68톤 수조가 이미 있다는 가정**이었고 열이 계속 쌓인다는 점을 빼먹었습니다. 지금 단계에서는 분쇄기가 맞습니다.
{: .warn}

</details>

## 순서

| 단계 | 할 일 | 정제 금속 |
|---|---|---|
| 지금 (사이클 12~) | 무차별 정제 → 쇄석기 → 광석 1,000 kg 분쇄 | 500 kg 확보 → 스마트 배터리·자동화 |
| 그다음 (냉방 전) | 정제 금속이 더 필요하면 **분쇄기로 더 갈기**. 연구는 정제된 혁신(소방서 폴), 고급 전력 제어 | 필요한 만큼 (열이 정제기의 1/26) |
| 냉방실 완성 뒤 | 제련 → 금속 제련소 + 헤비와트 연결 + 냉각수를 냉방실로. 냉방실이 차가울 때 몰아서 | 필요할 때마다 100 kg 단위 (강철은 터빈 뒤) |
| 정제기 이후 | 기체 원소 센서 → 특수복 세트 → 전도성 와이어·큰 변압기 | 특수복 세트 약 1,000 kg (단조기 400 + 거치대 2개 200 + 체크포인트 100 + 특수복 1벌 300) |

> **U60 지원 건물:** 쇄석기 근처 뒷벽에 **워크숍 도구 (Workshop Tools)**, 제련소 옆에 **단조 도구 (Forge Tools)** → 각각 +15% ([방 페이지 도면]({{ '/guide/core-base/rooms/' | relative_url }}#정제제련-공구-선반--단조-도구)). 쇄석기는 제련소 뒤에도 **철거 금지** (석회 등).
{: .tip}
