## 단계별 발전 플랜

{: .ico-grid}
1. {% include i.html n="Bog_Bucket" %} **A. 전력 0** 야생 수렁박 (Bog Bucket), 공급 텔레포터 켜기
2. {% include i.html n="Manual_Generator" %} **B. 400 W** 수동 발전기 (Manual Generator), 전기 그릴
3. {% include i.html n="Atmo_Suit" %} **C. 원유 진입 준비** 단열 통로, 환경 특수복, 3~4명
4. {% include i.html n="Oil_Refinery" %} **D. 원유 → 자체 전력** 석유 정제소 (Oil Refinery) + 천연가스 발전기
5. {% include i.html n="Petroleum_Generator" %} **E. 자립** 석유 발전기, 스마트 배터리

> **공급 텔레포터는 양쪽 다 현장 연구 (Field Research) 복제체가 켜야** 합니다. 입력은 양자역학싫어요, 출력은 연구 관심으로 뽑은 3번째 복제체가 Oozato로 가서.
{: .warn}

<summary>단계별 표와 A~E 상세</summary>

| 단계 | 대략 | 전력 | 식량 | 할 일 |
|---|---|---|---|---|
| **A. 전력 0으로 생존** | 지금~사이클 115 | **필요 없음** | 야생 수렁박 수확 + 화분 8그루 날것 | 뒷간, 피처 펌프로 오염된 물, **공급 텔레포터 켜기** |
| **B. 작은 전력** | ~사이클 125 | **수동 발전기 (Manual Generator) 400 W** + 작은 배터리 | 전기 그릴로 늪의 환희 (+1) | 단열 바닥, 식탁, 벵이과실 씨앗 받기 |
| **C. 원유 진입 준비** | ~사이클 135 | B 유지 | 벵이과실 시작 (주변 황을 캐서) | 원유 쪽으로 단열 통로, 환경 특수복, 3~4명으로 충원 |
| **D. 원유 → 자체 전력** | ~사이클 150 | **석유 정제소 + 천연가스 발전기 800 W** → 석유 발전기 2,000 W | 수렁박에 발전기 오염된 물 | 처음 켤 전기는 배터리 충전이나 Persephazon 석탄 |
| **E. 자립 기지** | 그다음 | 석유 발전기 + 스마트 배터리 | 벵이과실 + 황 분출구 | 물 체 순환, 전해조, 남는 석유를 Persephazon에 |

**A. 전력 0으로 생존 (지금)**

전기가 하나도 없어도 되는 것만 짓습니다.

- **식량:** 주변 **야생 수렁박**부터 수확하고, 뽑아서 씨앗을 모아 **재배 박스 (Planter Box) 8그루**. 전기가 없으니 처음엔 날것으로 먹어요 (품질 보통). 수렁 젤리 1개가 1,840 kcal라 야생 몇 그루만 따도 2명이 며칠 버팁니다.
- **공급 텔레포터 켜기:** 입력(Persephazon)과 출력(Oozato) **양쪽 다** 현장 연구 (현장 연구) 스킬 복제체가 한 번씩 켜야 합니다. Oozato 2명은 스킬 포인트가 없으니, 이렇게 하세요.
  1. Persephazon에서 양자역학싫어요(현장 연구)가 **입력 쪽**을 켭니다.
  2. **충원할 3번째 복제체**를 연구 관심으로 뽑아 고급 연구 → 현장 연구를 찍고 텔레포터로 Oozato에 보내 **출력 쪽**을 켭니다. 연구원이 5사이클 넘게 자리를 비우지 않아도 돼요.
  3. 입력 옆엔 컨베이어 적재기, 출력 옆엔 컨베이어 투하기가 같이 묻혀 있어서 **적재기에 음식·씨앗을 넣으면 건너갑니다.** 와이어도 같이 있으니 전력이 필요하면 게임 안 툴팁을 확인하세요.
  4. 켜지면 Persephazon 음식 10사이클치와 벵이과실 씨앗을 먼저 보냅니다.
- **물:** 수렁박 물은 **피처 펌프 (Pitcher Pump)** 로 가까운 오염된 물 웅덩이에서. 8그루 = 320 kg/사이클.
- **산소:** 시작 바이옴의 오염된 진흙·오염된 물이 오염된 산소를 계속 내뿜어서 한동안 숨 쉬는 건 문제없습니다.
- **화장실:** 뒷간 (전기·배관 없음). 나오는 오염된 흙은 일단 보관.

**B. 작은 전력**

- **수동 발전기 400 W** 한 대 + 작은 배터리 1~2개. 쓰는 곳은 **전기 그릴 60 W, 조명 정도**라 복제체가 하루 잠깐만 돌리면 됩니다.
- Persephazon 주둥가리 목장에 석탄이 남으면 공급 텔레포터로 보내 **석탄 발전기 (600 W, 석탄 600 kg/사이클)** 를 잠깐 돌릴 수도 있어요. 상시용은 아닙니다.
- 기지 남쪽 바닥에 **절연 타일 한 줄**: 아래 원유 열이 올라오는 걸 막아요.

**C. 원유 진입 준비**

- 원유 쪽은 60°C를 넘습니다. **절연 타일로 둘러싼 통로**를 파고 내려가고, 작업은 **환경 특수복**을 입고 합니다 (연구는 Persephazon과 공유. 환경 특수복 거치대는 120 W라 B단계 전력이 있어야 함).
- 원유층 바로 위가 아니라 **조금 떨어진 곳에 공장 칸**을 미리 파 둡니다. 기지와는 절연 타일 두 겹 이상.
- 이때 **3~4명으로 충원** (요리·농사 1명, 기계 운영 1명).

**D. 원유 → 자체 전력**

- 원유 웅덩이에 **액체 펌프** → **석유 정제소** (원유 10 kg/s → 석유 5 kg/s + 천연가스 90 g/s, 480 W) → 천연가스를 **천연가스 발전기 (800 W)** 에. 위키 계산으로 석유 정제소 + 펌프를 **거의 혼자 돌립니다.**
- 문제는 **처음 켤 전기**입니다. 수동 발전기로 배터리를 채워 두거나, Persephazon 석탄을 받아 한 번만 시동을 거세요. 한번 돌면 끄지 않습니다.
- 석유가 쌓이면 **석유 발전기 (2,000 W)**. 오염된 물 750 g/s가 나오니 수렁박 물로 돌리고, 이산화탄소는 아래로 깔리게 공장을 기지보다 아래에.

**E. 자립 기지**

아래 상세 그대로: 식량은 벵이과실 + 황 분출구로, 전력은 석유, 물은 물 체 순환.

</details>

## 수렁박: 지금 환경에 맞는 작물

{: .ico-grid}
- {% include i.html n="Bog_Bucket" %} **어두워도 자람** 오염된 물 40 kg/그루
- **10~30°C** 원유·뜨거운 곳에서 멀리
- {% include i.html n="Electric_Grill" %} **구우면 늪의 환희 (Swampy Delights)** 1명당 2.95그루
- {% include i.html n="Planter_Box" %} **2명 8그루, 4명 15그루**

<details class="nums" markdown="1">
<summary>수렁박 수치 전체</summary>

이 행성의 늪지대 생물군계 (Swampy Biome) 토박이 작물입니다. **어두워도 자라고 오염된 물을 먹어서** 이 환경에 딱 맞아요.

| 항목 | 값 |
|---|---|
| 온도 | **10~30°C** (밖이면 성장 멈춤) |
| 물 | **오염된 물 40 kg/사이클** (그루당) |
| 빛 | 필요 없음 (어두운 걸 좋아함) |
| 대기 | 산소·오염된 산소·이산화탄소 |
| 수확 | 수렁 젤리 (Bog Jelly) 1,840 kcal / 6.6사이클, **4사이클이면 상함** |
| 화분 | **재배 박스(Planter Box)에도 심을 수 있음** (재배 타일도 됨) |
| 몇 그루 | 날것 1명당 **3.6그루**, 그릴로 구우면 **2.95그루** |
| 굽기 | 전기 그릴: 수렁 젤리 → 늪의 환희 (Swampy Delights) 2,240 kcal, 품질 +1 |

- **2명 → 8그루, 4명 → 15그루.** 오염된 물은 15그루면 600 kg/사이클이라 물웅덩이로는 언젠가 바닥납니다. 그래서 벵이과실이나 석유 발전기 오염된 물로 넘어가요.
- 온도가 30°C를 넘는 곳이면 안 자랍니다. 농장은 **침실 아래쪽, 원유·뜨거운 곳에서 먼 곳**에 두고 절연 타일로 막으세요.
- 그릴은 **조리 (Cooking) 스킬**이 있어야 돌아갑니다. 사기 여유가 큰 배시시(11/1)에게 찍어 두면 됩니다.

</details>

## 벵이과실 + 황 분출구: 무한 식량

{: .ico-grid}
- {% include i.html n="Liquid_Sulfur_Geyser" %} **액체 황 분출구 (Liquid Sulfur Geyser)** 기름 늪엔 항상, 1.5 kg/s
- {% include i.html n="Grubfruit_Plant" %} **호리호리한 벵이과실 (Spindly Grubfruit)** 황 10 kg/그루, 15~50°C
- {% include i.html n="Electric_Grill" %} **구우면 1명당 3.33그루** 4명 14그루
- **농장에 단벌레·벵이벵이 넣지 않기** 수확 주기 8사이클로

<details class="nums" markdown="1">
<summary>벵이과실 수치, 황 다루기, 분출구 하나로 자립</summary>

기름 늪 소행성에는 **액체 황 분출구 (Liquid Sulfur Geyser)가 항상** 있습니다 (평균 1.5 kg/s, 165°C). 황은 벵이과실의 비료라서, 이게 Oozato의 **무한 식량원**이에요.

| 항목 | 값 |
|---|---|
| 씨앗 | **Persephazon 황무지 (Wasteland)의 야생 벵이과실**에서 캐서 공급 텔레포터로 보냄 |
| 온도 | **15~50°C** (수렁박보다 훨씬 너그러움) |
| 비료 | **황 10 kg/사이클** (그루당), 물·빛 필요 없음 |
| 수확 | 호리호리한 벵이과실 (Spindly Grubfruit) 800 kcal / 4사이클 |
| 굽기 | 전기 그릴: 로스트 벵이과실 견과 (Roast Grubfruit Nut) **1,200 kcal**, 품질 +1 |
| 몇 그루 | 구우면 **1명당 3.33그루** → 4명 14그루, 황 140 kg/사이클 |

- **농장에 단벌레·벵이벵이를 넣지 마세요.** 호리호리한 벵이과실은 동물 없이 키우는 방식이고, 동물이 돌보면 벵이과실로 바뀌어 수확 주기가 8사이클로 길어집니다.
- 처음엔 **땅에 묻힌 황을 캐서** 쓰고, 분출구는 그다음에 길들입니다. 액체 황은 115°C 아래로 식으면 고체 황이 돼요. 분출구 하나(하루 약 900 kg)면 벵이과실 90그루분이라 한참 남습니다.
- 위키 공략: 황 분출구로 **벵이벵이·단벌레 목장**까지 하면 고기·설탕(벵이과실 잼)에, 벵이벵이가 싸는 진흙을 **슬러지 프레스 (Sludge Press)** 로 흙+물로 바꿔 **분출구 하나로 자립**할 수 있습니다. 4명 넘게 키울 때 다음 목표예요.

</details>

## 원유 설비 (나중에 많이 뽑을 것)

{: .ico-grid}
- {% include i.html n="Oil_Refinery" %} **석유 정제소** 원유 → 석유 + 천연가스
- {% include i.html n="Natural_Gas_Generator" %} **천연가스 발전기** 정제소를 거의 혼자 돌림
- {% include i.html n="Petroleum_Generator" %} **석유 발전기 (Petroleum Generator)** 2,000 W, 오염된 물 = 수렁박 11그루분
- {% include i.html n="Oil_Well" %} **유정 (Oil Well)** 원유층 위에만

> 출력이 75~300°C. **산업 블록은 절연 타일로 기지·농장과 떼기** (수렁박 30°C 한계). CO₂가 가라앉으니 공장은 기지보다 **아래.**
{: .heat}

<details class="nums" markdown="1">
<summary>설비별 수치</summary>

| 설비 | 하는 일 | 메모 |
|---|---|---|
| 석유 정제소 (Oil Refinery) | 원유 10 kg/s → 석유 5 kg/s + 천연가스 90 g/s | 480 W, 복제체가 운영 |
| 천연가스 발전기 | 석유 정제소 천연가스로 800 W | 석유 정제소+펌프를 거의 혼자 돌림 |
| 석유 발전기 (Petroleum Generator) | 석유 2 kg/s → **2,000 W** | **오염된 물 750 g/s** + 이산화탄소 500 g/s |
| 유정 (Oil Well) | 물 1 kg/s → 원유 3.33 kg/s (90°C) + 천연가스 (300°C) | 원유층 위에만. 물은 못 돌려받음 |

- **석유 발전기 1대 = 오염된 물 450 kg/사이클 = 수렁박 11그루분.** 원유 공장을 돌리면 1단계 농장이 다시 지속 가능해져요. 이산화탄소는 아래로 가라앉으니 공장을 기지보다 **아래**에.
- 유정·석유 정제소 출력은 75~300°C입니다. **산업 블록은 절연 타일로 기지·농장과 떼어** 두세요 (수렁박 30°C 한계).
- 남는 석유는 공급 텔레포터로 Persephazon에 보내 플라스틱(폴리머 프레스)과 발전에 씁니다.

</details>

## 오래 놔둬도 되는 기지 체크리스트

- [ ] 식량: 냉장고(전력 120 W)나 차가운 곳에 **10사이클치** 쌓임, 농장 수확 ≥ 소비
- [ ] 화장실: 뒷간 → 수세식 + 세면대, **물 체 (Water Sieve)** 로 오염된 물 → 물 순환
- [ ] 산소: 지금은 오염된 산소 (늪 진흙·오염된 물이 계속 내뿜음). 사람이 늘면 물 체 물로 전해조
- [ ] 전력: 스마트 배터리 → 발전기 자동
- [ ] 사기: 식탁(식당), 침대 → 막사, 구운 음식(+1). 노먼 12/6, 배시시 11/1이라 여유 있음
- [ ] 사람: 2명 → **4명** (요리·농사 1명, 기계 운영 1명 추가)
