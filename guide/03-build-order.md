## 전체 흐름

| 구간 | 대략 사이클 | 할 일 | 다 하면 |
|---|---|---|---|
| **극초반** | 1~20 | 화장실 → 산소 → 농장 → 연구 → 침실 → 수조 → 식당 → 석탄 발전기 | 복제체가 죽지 않고, 생활이 편해짐 |
| **초반** | 20~80 | 수조 완성 → 수트 스킬 → 금속 정제 → 전기분해기 산소 → 온도 관리 → 간헐천 → 환경 특수복 | 여기까지 하면 고인물 |
| **중반** | 80~150 | 원유 바이옴 → 지상 개통 → 강철 양산 → 목장 | 산업 기반 완성 |
| **후반** | 150~ | 운석 대비 → 우주 탐사 → 로켓으로 후반 재료 → 극후반 체제 | 끝없는 확장 |

> 사이클은 참고용입니다. 각 단계가 **안정적으로 돌아가는지** 확인하고 다음으로 넘어가세요.
{: .tip}

## 극초반 작업 목록

### 1. 화장실 만들기

**바닥 타일 18칸이 가장 효율적입니다.** 그 위에 아래를 놓습니다.

- 간이 화장실 (Outhouse) 4개
- 세면기 (Wash Basin) 4개 — 화장실에서 나오는 방향으로
- 수동 펌프 (Pitcher Pump) 1개 — 아래 물웅덩이에서 물을 뜸

{% include shot.html src="bathroom-first.jpg" caption="맨 윗층 18칸에 세면기 4개(초록 화살표 방향)와 간이 화장실 4개. 아래층이 포드와 작업 공간, 왼쪽 아래 물웅덩이에 수동 펌프." %}

### 2. 산소 생성기 만들기

**산소 확산기 (Oxygen Diffuser)** 를 포드 층에 둡니다. 근처 조류를 캐서 채워 주세요. 1대가 복제체 약 5명분입니다.

{% include shot.html src="oxygen-diffuser.jpg" caption="포드 옆에 산소 확산기와 연구소, 작업대를 한 줄로." %}

### 3. 식량 해결용 농장 만들기

- **복제체 1명당 4그루**를 심고, 수확한 걸로 **이빵 (Liceloaf)** 을 자동 제작하게 해두면 식량이 해결됩니다.
- 농장 타일 (Farm Tile)을 한 줄로 깔면 관리가 쉽습니다.

{% include shot.html src="farm-liceloaf.jpg" size="half" caption="농장 타일 9칸을 한 줄로. 바로 아래층에 이동 통로." %}

> **여기까지 3개만 잘 해도 복제체는 죽지 않습니다.** 화장실, 산소, 식량.
{: .tip}

### 4. 연구 시설 만들기

연구소 (Research Station)를 짓고 연구 담당을 붙입니다. 연구 순서는 **식량 → 전력 → 파이프 → 환기** 순서가 무난합니다. 연구 화면 위쪽 검색창에 건물 이름을 넣으면 빨리 찾을 수 있어요. 전체 순서와 사이클별 타이밍은 [연구 순서와 타이밍]({{ '/guide/research/' | relative_url }})에 정리했어요.

### 5. 침실 만들기

간이 침대 (Cot)를 복제체 수만큼. 방 안에 산업 기계를 두지 않아야 막사 보너스가 붙습니다. 방 규격은 [건축 규격 & 팁]({{ '/guide/build-specs/#방room-규격' | relative_url }})을 보세요.

### 6. 수조 만들기

물웅덩이 주변을 파서 **물을 모아둘 공간(수조)** 을 만듭니다. 나중에 수세식 화장실, 전기분해기, 농장이 전부 이 물을 씁니다.

{% include shot.html src="water-tanks.jpg" caption="물웅덩이를 넓게 파서 수조 3개를 만든 모습. 가운데 세로 통로로 각 층을 연결." %}

### 7. 식당 만들기

식탁 (Mess Table)을 여러 개 놓고 방으로 감싸면 식당 보너스(사기 +3)가 붙습니다. 나중엔 장식품을 더해 큰 회관 (Great Hall)으로 키웁니다.

<div class="shot-grid">
{% include shot.html src="mess-hall-early.jpg" caption="초반 식당. 긴 방에 식탁을 쭉 놓고 양 끝에 문." %}
{% include shot.html src="washroom-dining-stack.jpg" caption="발전한 모습. 위층 화장실, 가운데 그림으로 꾸민 식당, 아래층 설비를 층으로 쌓음." %}
</div>

### 8. 석탄 발전기 사용하기

수동 발전기에서 **석탄 발전기 (Coal Generator)** 로 넘어가면 복제체가 쳇바퀴를 안 돌려도 됩니다. 스마트 배터리로 필요할 때만 켜지게 하세요.

{% include shot.html src="coal-generator-floor.jpg" caption="작업대 층 아래에 발전기와 배터리를 모아 둔 발전 층. 왼쪽에 수동 펌프." %}

이렇게 하면 생활이 편해집니다.

## 초반 작업 목록

### 수조 완성

극초반에 판 수조를 마무리하고, 펌프와 파이프로 화장실·농장에 연결합니다.

### 복제체 레벨 3~4 → 수트 착용 스킬

1. 수조를 완성하고
2. 복제체를 **전부 레벨 3~4** 까지 올려서 **수트 착용 스킬 (Exosuit Training)** 을 찍습니다.
3. 금속 정제 + 전기분해기로 산소를 만들어서
4. **환경 특수복 거치대 (Exosuit Checkpoint / Dock)** 를 **침실 앞**에 설치합니다.

> 환경 특수복 = **전기 + 산소**. 거치대에 와이어와 산소 파이프를 둘 다 연결해야 합니다.

{% include shot.html src="bedrooms-exosuit.jpg" caption="4층짜리 침실 앞에 층마다 환경 특수복 거치대를 줄지어 설치. 전도성 와이어(2,000W)로 전력, 기체 파이프로 산소 공급." %}

### 금속 정제

**금속 정제기 (Metal Refinery)** 로 정제 금속을 만듭니다. 특수복, 고급 건물, 나중의 강철까지 전부 여기서 시작합니다. 정제기는 냉각수가 많이 뜨거워지니 냉각수 파이프를 따로 빼두세요.

### 전기분해기로 산소 만들기 (18×5 모듈 2개)

전기분해기 (Electrolyzer)는 물로 산소와 수소를 만듭니다. 아래는 **가로 18 × 세로 5칸 모듈을 2개** 쌓은 구조입니다.

{% include shot.html src="spom-2x.jpg" caption="모듈 2개를 위아래로. 버섯 모양이 가스 펌프(240W), 오른쪽 끝 흰 장치가 전기분해기(120W). 펌프가 방마다 산소와 수소를 따로 뽑아냄." %}

<div class="shot-grid">
{% include shot.html src="spom-power.jpg" caption="전력 오버레이. 가스 펌프 240W, 전기분해기 120W. 전도성 와이어 한 줄에 현재 480W / 최대 1,440W로 2,000W 한도 안." %}
{% include shot.html src="spom-gas.jpg" caption="기체 오버레이. 파란 파이프 = 산소 → 오른쪽 침실 앞 특수복 거치대로. 분홍 파이프 = 수소 → 발전기로." %}
{% include shot.html src="spom-liquid.jpg" caption="액체 오버레이. 물이 각 모듈 전기분해기로 들어감." %}
{% include shot.html src="spom-sensors.jpg" caption="자동화 오버레이. 각 방에 압력 센서를 달아 펌프를 제어." %}
</div>

> <span class="memo">센서 설정</span> **수소 4,000 / 산소 10,000** — 압력 센서 설정값(g). 방 안 기체가 이 값을 넘으면 펌프나 전기분해기를 멈추게 합니다.
{: .warn}

전기분해기 원리와 물 수급은 [장기 평형 설계]({{ '/guide/sustainability/#산소-전기분해기-시스템-spom' | relative_url }})에 정리했습니다.

### 9. 온도 관리 시설 만들기

**증기 터빈 (Steam Turbine) + 수냉 조절기 (Thermo Aquatuner)** 조합입니다. 수냉 조절기가 냉각수의 열을 증기 방에 버리고, 증기 터빈이 그 열을 전기로 바꿉니다.

### 10. 간헐천 활용하기

물 분출구, 증기 분출구, 천연가스 분출구 같은 **간헐천 (Geyser)** 을 막아서 길들이면 물과 전력 문제가 끝납니다. 자세한 건 [장기 평형 설계]({{ '/guide/sustainability/' | relative_url }}) 참고.

### 11. 환경 특수복 입히기

위험 구역(뜨거운 곳, 오염 구역)에 들어갈 복제체에게 환경 특수복을 입힙니다.

> **여기까지 하시면 고인물입니다.**
{: .tip}

### 물 소독 시스템 (염소방)

정화한 물에 남은 병균은 **염소 (Chlorine) 가스로 채운 방**을 통과시키면 죽습니다. 물이 염소방에 **150~200초** 머물도록 파이프 길이를 잡으세요.

## 중반 작업 목록

1. **원유 바이옴 뚫기** — 석유층은 뜨거우니 단열·내열 재료를 준비하고 들어갑니다. ([바이옴 확장 타이밍]({{ '/guide/biome-expansion/' | relative_url }}) 참고)
2. **지상까지 길 뚫기** — 표면을 열면 운석이 떨어지기 시작합니다.
3. **강철 양산하기** — 금속 정제기로 강철을 만들어 고온용 건물에 씁니다.
4. **목장** — 주둥가리(Hatch) 목장 자동화. 참고: [Reddit: Automated Hatch Farm revisited](https://www.reddit.com/r/Oxygennotincluded/comments/14yyrl0/automated_hatch_farm_revisited/)

## 후반 작업 목록

1. **운석 대비 방탄 작업 시작하기**
2. **우주 탐사 시작하기**
3. **우주선 발사해서 후반 재료 구하기**
4. **기지를 극후반 체제로 변경하기**

> 중·후반은 아직 메모 수준입니다. 플레이하면서 채워 나갈 예정이에요.
